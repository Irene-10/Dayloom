# 数据与隐私说明

## 默认电脑模式

`node server.js` 默认只监听本机回环地址。所有任务、知识卡片、打卡、心情与设置以完整快照保存到本机 SQLite，无需账号；浏览器使用 localStorage 和 IndexedDB 保存缓存及尚未写入的修改。

本机版会向同一地址的 `/api/` 请求读写数据，不包含第三方统计、广告、遥测或远程字体。没有运营方自动收集你的内容。点击文档中的外部链接会打开对应网站，不属于工作台的数据保存请求。

SQLite 和 JSON 导出文件没有静态加密。Windows 账户或磁盘的访问权限决定谁能读取文件；本机模式也不向共用同一 Windows 账户的人提供独立身份验证。

清除浏览器数据不会删除已成功写入的 SQLite；尚未写入的浏览器修改以及 HTML 体验模式的数据可能丢失。硬盘故障仍可能影响数据库，建议定期导出到另一处存储。

## 可选账号服务

显式设置 `DAYLOOM_MODE=accounts` 才启用账号服务。它是自行部署的服务，不是 Dayloom 提供的在线账号平台。注册信息及内容保存在运行该服务的设备上；其管理员有能力读取数据库。

密码使用 scrypt 加随机盐保存散列；登录 Cookie 设置 HttpOnly、SameSite，配置 HTTPS 来源时再设置 Secure。密码散列不等于内容加密。公网部署须使用 HTTPS，否则内容传输没有 TLS 保护。

不同账号的数据分开保存。同账号同步使用完整快照，冲突需要选择版本，不支持自动逐条合并。当前没有邮箱验证、密码找回和自助注销账号流程；不作为已准备好的公共注册服务发布。

## AI 阅读

不配置 API 时，“今日重读”只在本机按标签、时间和回顾记录选择卡片，不调用外部模型。

配置 AI 服务后，只有用户点击“生成知识碰撞”，并在发送预览中确认，所列卡片才会提交到填写的 API 地址。生成请求包含预览中的卡片正文、标签、日期和卡片 ID，以及通用生成提示、模型名称和用于鉴权的 API Key；不会自动发送预览之外的知识卡片。通用提示词不包含演示用户、作者的私人资料或预置项目分析。

“测试连接”会向所填服务发送一条简短的测试提示、模型名称和用于鉴权的 API Key。第三方服务还能看到正常网络请求所包含的信息，并可能记录或处理请求内容；使用前请查看对应服务的价格、日志留存和隐私规则。

API 地址、模型名和 API Key 保存在本机 SQLite 的独立设置表中，不会写入工作台 JSON 状态，也不会随 JSON 备份导出。生成后的阅读结果会作为工作台数据保存在本机，并随 JSON 备份导出。当前版本没有对数据库中的 Key 额外加密；能够访问该 Windows 用户数据目录的人可能读取它。需要更高安全性时，请使用权限受限、可随时撤销的专用 Key。

## 删除与迁移

“设置 → 清空全部数据”会清空当前工作空间；数据库连接正常时也会写入空状态。它不会删除你此前导出的备份、其他工作空间或账号注册记录，也不是磁盘级安全擦除。

卸载代码文件夹不会删除外部数据目录。彻底移除前，在设置中确认实际路径、导出所需内容并停止服务，再自行删除那个数据目录和浏览器网站数据。不要删除其他应用的数据。

导入 JSON 会替换当前内容，并可能继续写入所连接的数据库。更换服务地址、数据库或 Windows 账户前，先导出备份。
